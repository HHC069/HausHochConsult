# HausHoch Consult OnePager – GitHub Pages

Diese statische Fassung ist für einen eigenständigen Unterordner in einem bestehenden GitHub-Pages-Repository vorbereitet.

## Empfohlene Ablage

Den vollständigen Inhalt dieses Ordners nach `onepager/` im Repository kopieren. Der Aufruf erfolgt anschließend unter:

`https://OWNER.github.io/REPOSITORY/onepager/`

## Enthalten

- vollständig statisches HTML, CSS und JavaScript
- alle Bilder lokal im Ordner `assets/`
- keine Installation und kein Build erforderlich
- responsive Darstellung für iPhone, Android, Tablet und Desktop
- anonyme Teamdarstellung ohne Namen oder Funktionen
- reduzierte Animationen mit Rücksicht auf `prefers-reduced-motion`

## Prüfung

Vor dem Merge in GitHub kontrollieren:

1. GitHub Pages ist für das Repository aktiviert.
2. Der bestehende Pages-Workflow veröffentlicht den Repository-Inhalt.
3. Die Seite unter `/onepager/` öffnet ohne 404-Fehler.
4. Telefon-, E-Mail-, Hauptseiten-, Impressums- und Datenschutzlinks funktionieren.
